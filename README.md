# FulfillmentMax Landing Page

Landing page for FulfillmentMax - a fulfillment service for ecommerce brands.

## Overview

This is a professional landing page built for FulfillmentMax with:
- Hero section with company promise
- Contact section with Calendly integration
- "What We Do" section with two columns:
  - We Do This (operational services)
  - We Help You Do That (growth & strategy services)
- Testimonials section (placeholder)
- FAQ section with expandable questions
- Client Facts section (placeholder)

## Design

**Color Scheme:**
- Primary Blue: #0066cc
- Secondary Blue (Light): #e6f2ff
- Black/Text: #1a1a1a
- White: #ffffff

**Layout:**
- Responsive design
- Mobile-first approach
- Contact section: Calendly (left) + Form (right) in equal squares
